# @stargantt/plugin-interaction

Official StarGantt plugin: pointer and keyboard interaction — selection, drag-edit, snapping, tooltips, context menu, zoom toolbar, clipboard, filter/search, edit dialog and side panel.

Part of [StarGantt](https://github.com/wintermaples/star-gantt) — a plugin-based Gantt
chart library with zero runtime dependencies.

- Documentation: https://wintermaples.github.io/star-gantt/
- Live examples: https://wintermaples.github.io/star-gantt/examples/
- Repository: https://github.com/wintermaples/star-gantt

Most applications should install the all-in-one bundle instead:

```bash
npm install stargantt
```
