StarGantt v2 — export range (PNG/JPEG/SVG)

What's on this page

toPng(options)/toSvg(options) accept a per-call range: "viewport" (visible only), "full" (the whole task extent), or an explicit { start, end } span (here, the first 20 days). JPEG shares the same raster pipeline as PNG, via toPng({ format: "jpeg", quality }) — quality 0..1, anything else (including omitting it) leaves the encoder's own default (~0.92) in charge. JPEG has no alpha channel, so this page configures background: "#ffffff", which is also what the encoder falls back to on its own.
