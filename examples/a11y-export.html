StarGantt v2 — accessibility & PNG export

What's on this page

Navigate the gantt chart rows with the keyboard (arrow keys, Enter key). A parallel ARIA treegrid is generated for screen-reader support, here with the opt-in dependency read-out, shortcut-help dialog and summary table turned on (see the keyboard panel below the chart). The export button renders the chart's canvas surfaces (timeline, bars, dependencies) as a PNG image; the tree-grid pane is DOM, not canvas, so it is not part of the export.

⌨️ Keyboard accessibility features

Tab into the chart, then: ? opens the shortcut-help dialog, built from the chart's live key bindings — one line per chord that carries a description, so the navigation and a11y shortcuts are listed while the undescribed edit chords below are not (shortcutHelp); Ctrl+Alt+S builds the visually hidden screen-reader summary table of every task and moves the focus into it, and closes it again (summaryTable); Ctrl+Alt+← / Ctrl+Alt+→ move the focused task's start edge by one day — the keyboard equivalent of dragging the bar's left handle, announced in the log to the right; and arrow-key navigation reads each row's predecessors and successors through aria-describedby (describeDependencies), mirrored in the read-out below. The buttons send those same keystrokes to the chart, so the features are reachable with a pointer too.
