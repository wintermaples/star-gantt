Performance features

The opt-in switches the library ships for large charts. The renderer switches and the dependency-line culling are resolved once when a plugin is created, so toggling one re-creates the chart — the loaded tasks are cleared and have to be loaded again, which is exactly the trade-off a host makes when it picks these options at composition time.

Deferred data

Deferred subtrees: none loaded. The load parks 4,000 child rows and 3,980 links as raw data — they exist nowhere in the store until a subtree is materialized.
