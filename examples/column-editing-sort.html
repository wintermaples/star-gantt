How to use

  • Double-click any cell to edit it. Select a row and press Enter to edit its first editable column (Name).
  • Click the "Priority" header to sort ascending, click again for descending, a third time to turn sort off.
  • Drag a header column boundary to resize that column.
  • Every edit dispatches task/update, so it is undoable.

Config toggles

  • wbs prepends a read-only "WBS" column (1, 1.1, …) computed from the store's sibling order; its header sorts numerically per segment.
  • columnLayout only changes what the pane displays — hidden and reordered columns keep their editing, sorting and resize behavior.
  • cellRenderers replaces how Progress and Status paint their cells; the headers, widths, editors and sorting are untouched.
  • rowClass adds a stripe and bolder text to rows whose Priority is 1.
  • collation gives the built-in Name header an Intl.Collator sort (numeric: true, so "Phase 2" precedes "Phase 10"). With it off the Name header stays inert — a column without compare does not sort.
