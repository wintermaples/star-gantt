StarGantt — context menu and clipboard

How to use

  • Right-press a bar to open the menu: Insert task, Duplicate task, Delete task, then Start link from here. Pick that last entry, right-press a second bar, and Link here from source becomes enabled — activating it creates an FS dependency. The pending source is one-shot: every menu opened while it is armed also offers Cancel link, and the source is dropped once the next menu invocation ends.
  • Right-press empty chart space for the background menu (Insert task at the root level).
  • The menu is keyboard-driven: it takes focus on open, ↑/↓ move (wrapping), Home/End jump, Enter or Space activate, Escape closes and gives focus back.
  • Extra menu entries toggles a page-local plugin that contributes two entries through contextmenu/items — they select the right-pressed task, then call the public clipboard commands, showing how a third-party plugin extends the menu.
  • Select bars (click, Ctrl/Cmd-click, Shift-click, or the Select summary branch button), then Copy: the whole subtree plus every link with both endpoints inside the selection is captured. Paste inserts it after the anchor row with fresh ids and remapped links; Duplicate (or Ctrl/Cmd + D) copies in place without touching the held clipboard.
  • With focus inside the chart, Ctrl/Cmd + C and V use the system clipboard through the native copy / paste events, so rows can travel to and from a spreadsheet.
  • Paste rows as cells feeds the textarea's tab-separated rows to a foreign-text paste. Text is written onto the rows from the anchor downward — the anchor is the focused row, else the first selected row — and any rows that outrun the grid become new root tasks appended at the end. Click a row first to move the anchor there.
  • Every clipboard or menu action is exactly one history entry: Undo reverses a whole paste, not one task at a time.
