StarGantt — multi-select and rubber-band

How to use

  • Click a bar to select only that bar.
  • Ctrl (Cmd on macOS) + click a bar to toggle its membership in the selection.
  • Shift + click a bar to select every visible row between the last non-Shift pick and that bar.
  • Press and drag on empty chart space (not on a bar) to rubber-band select every bar the rectangle touches; hold Ctrl/Cmd while dragging to add to the current selection instead of replacing it. Esc abandons a rubber-band in progress.
  • Hover a bar to see its tooltip (trigger: "both"); click still works too.
  • Ctrl/Cmd + A selects every task in the data store (shortcuts.selectAll). It only fires while the keyboard focus is inside the chart — click a grid row first — so the shortcut never hijacks the surrounding page.
  • Esc clears a non-empty selection (shortcuts.clearOnEscape). A rubber-band drag in flight wins: that first Esc abandons the drag, the next one clears.
  • Delete (with the focus inside the chart) opens the bulk-delete confirmation for the current selection (shortcuts.deleteSelected) — the same flow the Delete selected… button starts through SelectionService.deleteSelected(). Confirming removes every selected task in one transaction, so a single Ctrl/Cmd + Z brings them all back. Reset demo data reloads the page's default data.
  • Confirm mode switches between the plugin's built-in alertdialog (its wording comes from this page's messages overrides — Remove / Keep) and a host confirmDelete hook that replaces the dialog with a policy: it approves at most two rows at a time and refuses larger deletions. Either way the outcome is reported in the Confirmation outcome readout. Switching re-creates the chart, which also restores the data.
  • Keyboard: with a row focused (click a grid row, or Tab into the grid), Shift + ↑/↓ extends the selection from the row where the Shift sequence began to the newly focused row, and Ctrl (Cmd on macOS) + Space toggles the focused row's membership — both only while selection runs in mode: "multi", as configured here.
