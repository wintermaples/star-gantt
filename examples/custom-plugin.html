StarGantt — writing your own plugin

What's on this page

Six third-party plugins defined in this file: a weekend background layer and a today line (renderer/layers), a hit tester for the today line (renderer/hitTest), a tooltip provider for it (tooltip/content), a focusable keyboard marker plus an Alt+T shortcut (renderer/domOverlays + keys/bindings + a custom command), and an "at risk" HTML badge that places itself through the renderer's batched layout queue. Two of them register their own services, one claims a task.meta key, one declares its own extension point and another contributes to it. Plus one OFFICIAL plugin configured rather than replaced: presetStandard({ taskBars: { label } }).

Toggle the caption to watch the today-line pill resize to the measured text width.
