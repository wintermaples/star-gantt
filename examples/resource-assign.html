StarGantt v2 — resource assignment

What's on this page The Resources grid column (chips + an editor button), the assignment editor dialog, chip drag-reassign, and — below the chart — the auto-scheduler's effort tri-state, which recomputes duration/work/units on an assignment edit as part of the same undoable step.

Effort tri-state (fixed duration / work / units)

Three tasks opt into the auto-schedule engine's effort accounting through meta.effortMode and meta.work (work in milliseconds). The engine keeps work = duration × units, where units is the sum of the task's assignment rates, and appends its recomputation to the same transaction as the edit that triggered it — one Ctrl+Z reverts both together.
