StarGantt v2 — tree grid interaction

Visible rows: 0 Scroll position: 0, 0
Outline & structure Target task type: — Collapsed badges: none

Pick a target row, then indent, outdent or insert. Inside the grid pane Tab / Shift+Tab do the same to the active row; Escape releases Tab so it leaves the grid again.

Demo features

  • Expand/collapse tasks with the arrows on the left of the tree grid
  • Bulk control via the "Expand all" / "Collapse all" buttons
  • The grid pane (left) and the chart pane (right) scroll in sync
  • Summary tasks (project rows) get a taller row height than their children
  • Column definitions: task name, start date, end date, progress, custom column (description)
  • Scroll position is displayed in real time
  • Outline editing: indent/outdent the target row, or press Tab / Shift+Tab on the active row inside the grid pane (Escape releases Tab so it leaves the pane again)
  • Insert a row below the target or as its child — one undoable step each. A sibling insert targets the new row; a child insert keeps the parent targeted so its type flip stays visible
  • "Expand to level" sets the whole tree's expand state at once (display state only, not undoable)
  • Collapsed branches show a "(n)" hidden-descendant badge as plain text
  • Auto-summary: inserting a child under the plain "Routine maintenance" task promotes it to a summary in the same transaction — the "Target task type" readout flips to "summary" (the target stays on the parent), and the status line names the promotion

Public API usage

  • StarGantt.create() - initialize the gantt chart
  • presetStandard() - the standard plugin set
  • gantt.service("stargantt.rows") - access to the row model
  • gantt.service("stargantt.data") - access to the data store
  • gantt.dispatch("view/rowToggle", { id }) - expand/collapse operations
  • gantt.service("stargantt.rows").rows.subscribe(...) - row-set changes
  • gantt.on("view/scrolled", ...) - scroll events
  • gantt.dispatch("view/rowIndent" / "view/rowOutdent", { id }) - outline editing
  • gantt.dispatch("view/rowInsert", { id, position }) - insert a row
  • gantt.dispatch("view/expandToLevel", { level }) - bulk expand state
  • treeGrid: { outlineEditing: true, collapsedBadge: true } - Tab outlining and the "(n)" badge
  • definePlugin() - a custom plugin (column definition, row height customization)
