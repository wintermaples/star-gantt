How to use

  • Right-press a bar or a grid row and pick Insert task: the new task is a child of the task you pressed, starts where it starts, and is one grid cell long. Change the zoom level first and insert again to see the duration follow the cell — a day, a week, a month, a quarter.
  • Right-press empty chart space inside a task's row — beside the bar, in the same lane — and the same entry creates a child of that row's task at the pressed cell. The press names a date as well as a row, so the new bar lands under the pointer rather than at the task's own start.
  • Right-press an in-row bar of the collapsed "Content migration" row: that row is a split row — it paints its two children's bars instead of its own summary glyph — and the press names whichever child is under the pointer, so the insert goes under that child. The split row is unchanged afterwards: it shows the project's direct children only, and the new task is a level deeper.
  • Right-press the gap between those two bars — inside the project's row but over no child — and the row's own task is the parent, so the insert becomes a third direct child. It would have landed out of sight under a folded parent, so the entry expands the row right after adding it; press Collapse "Content migration" to fold it back and watch all three children share the project's row again.
  • Right-press below the last row for a top-level task at the pressed date.
  • Insert row under "Design system" dispatches view/rowInsert { id } with no position: the grid command defaults to "child" too, and gives the row the same one-cell span.
  • Every insert is exactly one history entry: Undo reverses it in one step.
