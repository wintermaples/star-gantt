Composition settings

One choice per group; applying rebuilds the chart from a fresh plugin list.

Why these are radio buttons, not checkboxes. Most groups below collect options that fight for the same surface — a bar's fill, a double-click, the bottom region's height, the store's contents. The library cannot arbitrate those for a host, so this page makes the broken combinations unreachable rather than letting you build one and then explaining the mess. The one exception is Overlays: v2's core arbitrates chart-pane corners itself through claimSlot("overlay-corner", …) and moves a displaced overlay to a free corner, so those groups are a layout preference, not a correctness constraint. Everything not in this dialog is set to a fixed, good value in the page source.
