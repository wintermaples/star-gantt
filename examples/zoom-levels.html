The chart also composes the opt-in interaction({ zoomControls: {...} }) group: a floating toolbar in the chart pane's bottom-right corner with −/+ buttons, a ladder slider and Fit / Today / Selected task actions. Because a11y({ zoomKeys: true }) is on, clicking a chart row and then pressing + or − steps the same ladder from the keyboard (the plain keys, not Ctrl++, which stays with the browser's page zoom). Every one of these paths anchors on the viewport centre and publishes through the timeline.zoomLevel store, so the readout above stays correct whichever you use.
